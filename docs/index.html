How to Install in 3 Steps

No command line or Python required. Works with FL Studio 21, 2024, and 2025+.

1

Download the Pack

Download fl-studio-themes-pack.zip from our GitHub Releases.

📦 fl-studio-themes-pack.zip Download ↗
2

Paste in Themes Folder

Extract all folders directly into your FL Studio Themes directory:

Windows: %USERPROFILE%\Documents\... Copy 📋
macOS: ~/Documents/Image-Line/... Copy 📋
3

Select in FL Studio

Open FL Studio and press F10 (Options $\rightarrow$ Theme settings). Select your favorite theme from the list!
